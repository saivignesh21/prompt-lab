# Prompt Lab

An interactive, client-side prompt strategy playground. Enter a brief, choose a goal, and get three ready-to-use prompt lenses: systems, human, and maker.

## Run it

No install or API key required.

1. Download the repository: click **Code → Download ZIP** on the [project page](https://github.com/saivignesh21/prompt-lab).
2. Extract the ZIP and open [`index.html`](./index.html) in any modern browser.
3. Write a brief, choose a goal, and select **Generate strategy**.
4. Pick one of the three prompt lenses and use **Copy prompt** to move it into ChatGPT or another AI tool.

### What it does

Prompt Lab turns one rough idea into three structured prompts:

- **Systems lens** maps actors, constraints, incentives, and trade-offs.
- **Human lens** focuses on user needs, emotions, and adoption.
- **Maker lens** creates a small, testable next step.

The repository currently holds the source code rather than a hosted public website. A shareable live link can be added by deploying it to GitHub Pages or another hosting service.

## Why it exists

Better AI outputs begin with a better framing of the problem. Prompt Lab helps turn an early, ambiguous brief into a prompt with clear constraints, desired form, and useful perspective.

All processing happens in the browser. The app does not call an AI service or transmit your input.
